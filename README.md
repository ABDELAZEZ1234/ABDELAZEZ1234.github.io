# Abdelazez Ashraf Mustafa, portfolio website

Live site: https://abdelazez1234.github.io/

This repository is the website. GitHub Pages serves `index.html` from the `main` branch.

## Edit the site

1. Open `index.html` in this repository and click the pencil icon (Edit).
2. Change the text between the tags, for example a project description or a course name.
3. Click **Commit changes**. The live site updates in about a minute or two.

## Add a course or project

In `index.html`, copy an existing block (an `<li>` item in a list, or an `<article class="card">` in Projects), paste it below, and change the words.

## Files

- `index.html`: the whole page, including its styles
- `robots.txt` and `sitemap.xml`: help search engines find the page. If the web address ever changes, update the address inside both files and inside `index.html` (search for `abdelazez1234.github.io`).
